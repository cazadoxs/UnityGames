# Lista de assets por nivel

Estado: **pendiente** en todos (se producen en el PC). Origen previsto: **AS** = Asset Store / banco de modelos, **IA** = ComfyUI (imagen o imagen→3D) + limpieza en Blender, **MX** = Mixamo, **P** = propio.

## Comunes a todos los niveles

| Asset | Origen | Notas |
|---|---|---|
| Cuerpo humanoide base con esqueleto oficial | AS / P | El esqueleto oficial se publica para modders (Vol. V §9) |
| Caballo de guerra y de monta (3 capas) | AS | Con su esqueleto y animaciones |
| Kit de animaciones de combate | MX + P | Ver `Animaciones.md` |
| Estandartes y banderas con tela simulada | P | Heráldica por facción con máscaras |
| Flechas, virotes, jabalinas (instanciables) | IA | Muy bajo polígono |
| Carros de suministro, barriles, sacos, tiendas | IA | Primer recorrido del pipeline (Vol. I §19.3) |
| Cadáveres y armas caídas | P | Variantes horneadas |
| VFX: polvo, humo, fuego, sangre, impactos | AS | Compatibles con URP |
| Cielo, niebla, lluvia | AS | Sistema de clima |
| Materiales de terreno: hierba, barro, tierra arada, roca, camino | IA | Tileables PBR |
| Vegetación europea: robles, hayas, matorral, hierba alta | AS | Con impostores |
